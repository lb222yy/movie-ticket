# CineMax 演示录屏脚本（5~10 分钟）

> 目标：完整覆盖「核心功能操作 + 代码讲解」，建议控制在 **8~9 分钟**。
> 录制工具：OBS Studio / Windows 自带 Xbox Game Bar（Win+G）/ 剪映录屏均可，输出 1080P、MP4。

## 一、录制前准备

1. 重新初始化演示数据，避免座位被占、订单过多：
   ```bash
   npm run init-db
   npm start
   ```
2. 浏览器使用无痕窗口，缩放 100%，关闭无关标签页；
3. 提前登录两个窗口（或用两个浏览器 Profile）：
   - 前台普通用户：`demo / demo123`
   - 后台管理员：`admin / admin123`
4. 准备好代码编辑器，打开这三个文件用于讲解：
   - `database/schema.sql`
   - `server/routes/orders.js`
   - `public/js/seat.js`

## 二、分镜脚本

### 00:00 – 00:40　开场（40 秒）
- 画面：项目首页整体，鼠标缓慢滚动一屏。
- 讲解词：
  > 这是我们的期末项目 CineMax 在线电影购票系统，题目 13。技术栈是 HTML5 + CSS3 + 原生 JavaScript，后端 Express，数据库 SQLite，实现了题目要求的全部 15 项功能，包括选座购票、电子票、退改签和数据看板。

### 00:40 – 01:40　首页与搜索（60 秒）
- 操作：
  1. 悬停轮播图 → 展示自动轮播与圆点切换；
  2. 在搜索框输入「星」→ 展示联想/结果，回车后观察搜索历史被记录到 `localStorage`；
  3. 点击类型筛选、查看票房榜与即将上映倒计时；
  4. 点击任意海报上的爱心收藏影片，再滚动到「我的想看」区块。
- 讲解：轮播用定时器 + DOM 切换；搜索历史存 localStorage，最多 8 条。

### 01:40 – 02:40　影片详情与评分（60 秒）
- 操作：
  1. 进入《多萝西》详情页，展示真实评分、演职人员、剧情简介（数据由豆瓣爬虫抓取）；
  2. 点击「播放预告片」弹窗；
  3. 切换日期 Tab，展示按影院分组的场次与余座；
  4. 在评论区打 9 分并发布影评，展示评分分布实时更新。
- 讲解：详情、演职人员、评分分布均由接口聚合返回，评论重复提交会更新而不是新增。

### 02:40 – 04:20　选座 → 支付 → 电子票（100 秒，核心）
- 操作：
  1. 选择今天晚间的 IMAX 场次，进入选座页；
  2. 展示座位图三态：可选、已售、他人锁定；指出 VIP 座与情侣座的加价；
  3. 选 2 个座位 → 下方结算栏实时显示总价 → 点击「确认选座，去支付」；
  4. 展示 15 分钟锁座倒计时；
  5. 支付弹窗选择「微信支付」→ 点击「立即支付」，等待模拟处理；
  6. 展示电子票：二维码、取票码、影院影厅座位、金额；
  7. 点击「打印电子票」展示打印预览后关闭。
- 讲解：锁座接口会写入 seat_locks；下单事务校验座位归属；支付后由服务端用 qrcode 生成二维码 DataURL。

### 04:20 – 05:40　我的票夹：倒计时 / 退票 / 改签（80 秒）
- 操作：
  1. 进入「我的票夹」，展示统计卡片、状态分栏与开场倒计时；
  2. 点击「电子票」再次打开二维码；
  3. 对另一笔已支付订单演示「改签」：选新场次 → 选等量座位 → 确认，提示补差价；
  4. 演示「退票」：确认框显示 5% 手续费与实退金额 → 确认后退款成功、座位释放；
  5. 展示待支付订单的「继续支付 / 取消订单」。
- 讲解：退票限开场前 2 小时；改签会把旧票置为 changed 并记录差额到 order_logs。

### 05:40 – 07:00　管理后台（80 秒）
- 操作：
  1. 使用 admin 登录 → 进入数据看板，展示 4 个 KPI、14 天票房折线、影院占比环形图、TOP 6 柱状图（刷新可见入场动画）；
  2. 电影管理：新增一部影片（选海报、加演职人员）→ 表格出现新行 → 再删除；
  3. 影院影厅：新增影厅并说明座位自动生成；
  4. 场次管理：新增场次，演示同厅冲突提示；
  5. 订单管理：演示管理员全额退款；评论管理：删除一条影评。
- 讲解：所有图表为原生 Canvas 手绘，按 devicePixelRatio 适配高清屏。

### 07:00 – 08:20　代码讲解（80 秒）
- 画面切到编辑器，依次展示：
  1. `database/schema.sql`：订单表、影票表，重点讲部分唯一索引
     `ux_ticket_seat_active ON tickets(showtime_id, seat_id) WHERE status IN ('held','valid')` 如何从数据库层防超卖；
  2. `server/routes/orders.js`：锁座 → 下单 → 支付的校验链，事务与过期清理；
  3. `public/js/seat.js`：座位图按 row/col 动态渲染与选中上限控制。
- 讲解：三层保险——锁座计时、接口校验、数据库唯一索引。

### 08:20 – 09:20　测试与部署（60 秒）
- 操作：
  1. 终端执行 `npm run test:api`，展示 33 项全部通过；
  2. 展示 `/api/health` 健康检查；
  3. 展示 `Dockerfile` 与部署说明（Render / 云服务器），说明在线访问地址。
- 讲解：接口测试覆盖鉴权、购票、退改签、评论、收藏与管理端 CRUD。

### 09:20 – 09:40　收尾（20 秒）
- 画面：首页全景。
- 讲解词：
  > 以上就是 CineMax 在线电影购票系统的完整演示。项目覆盖了课程要求的 HTML/CSS/JS/DOM/BOM/数据库/前后端全部知识点，代码与数据库脚本已上传仓库，感谢老师观看。

## 三、录制小贴士

| 事项 | 建议 |
| --- | --- |
| 分辨率 | 1920×1080，浏览器缩放 100%，避免出现滚动条抖动 |
| 鼠标 | 操作放慢，点击前停顿 0.5 秒，方便评委看清 |
| 声音 | 使用耳机麦克风，语速平稳；也可后期配音 |
| 剪辑 | 剪掉等待与失误片段，保留完整链路 |
| 文件 | 导出 H.264 MP4，命名 `CineMax-演示录屏-第X组.mp4`，控制在 5~10 分钟 |
| 兜底 | 录制前先完整走一遍，确认演示账号可用、场次有余座 |
