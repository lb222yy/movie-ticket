## 二、协作方式

| 环节 | 做法 |
| --- | --- |
| 需求与设计 | 共同过题目要求，拆出 15 项功能 → 画数据表关系 → 约定接口出入参 |
| 分支管理 | `main` 稳定版、`dev` 集成、`feature/*` 按模块开发，合并前互相 Review |
| 提交规范 | `feat:` / `fix:` / `style:` / `docs:` / `test:` 前缀，单次提交聚焦一个功能点 |
| 联调 | 后端先提供接口与演示数据，前端按 `{ success, message, data }` 约定联调，Postman / 测试脚本验证 |
| 验收 | 全链路演示走查 + `npm run test:api` 33 项断言全部通过 |
